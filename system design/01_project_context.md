# Project Context: Human-Centric Agency
## Overview
A modern agency platform offering Branding, Media Buying, and Web Development.

## "Human" vs. "AI" Design Philosophy
To avoid the generic "AI-generated" look, we prioritize:
- **Typography:** Using high-contrast pairs (e.g., a sophisticated Serif for headings and a clean Sans-Serif for body).
- **Textures:** Using subtle film grain, paper textures, and noise overlays instead of flat vector gradients.
- **Micro-Interactions:** Using "physical" motion (spring physics) instead of linear fades.
- **Asymmetry:** Avoiding perfect grid alignments to make the site feel "hand-crafted."
- **Real Imagery:** Avoiding overly glossy AI-style stock photos in favor of raw, authentic-looking visuals.

## Core Service Pillars
1. **Branding:** Visual identity and strategy.
2. **Social Media:** Media buying and page management.
3. **Web Development:** Bespoke, high-performance Next.js sites.
